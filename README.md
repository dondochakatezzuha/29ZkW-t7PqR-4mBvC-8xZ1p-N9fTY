This public site was installed for the TGC Discord archive. It currently only contains whatever the owner's local TGC Bridge has **explicitly approved and published**. The local bot and its full archive remain on the owner's PC.

## Getting the bot and website together

The owner's **TGC All-in-One v6 package** contains `TGC_Start_Everything_v6.exe` and `TGC_Live_Bridge_v6.exe`. When opened on the Windows PC with `D:\TGC`, the one-click launcher opens the existing bot startup script and the Bridge's local dashboard together. The Bridge reads original bot outputs on `D:\\TGC` directly. No Google Drive is used. To publish a public-safe snapshot, enter a fine-grained token limited to this repo, check the exact filenames and contents, then click Start GitHub mirror. Checking the optional **Remember securely** box stores the token encrypted using Windows DPAPI and resumes previously approved syncing on future starts. v6 requires a new review and explicit approval before publishing the broader file selection.

**GitHub Pages source:** branch `main`, folder `/docs` (already configured). The generated snapshot replaces the website inside `docs/` when it syncs. The repo URL stays stable.

**Important:** This is a public text mirror of approved original exports, not a copy of the entire local archive (binary media stays local). v6 splits large text into numbered parts and can upload much more text, subject to a protective 650 MiB publishing budget and the GitHub Pages 1 GB site limit. A random repo name doesn't protect data. The current bridge has size/file limits and filters private/admin paths, but users still need to review text manually. Never publish bot tokens, personal data, or unapproved Discord messages.

**For future chats:** read [CHATGPT_READ_THIS.md](CHATGPT_READ_THIS.md), open the *current* catalog, and follow sources. Do not assume missing records are absent from the complete archive.
