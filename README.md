# TGC Knowledge Library

An organized, publicly readable **partial archive** of approved TGC game exports, published from a local Discord bot's files via TGC Live Bridge.

**[Open the library site](https://dondochakatezzuha.github.io/29ZkW-t7PqR-4mBvC-8xZ1p-N9fTY/)** · [Read raw JSON catalog](docs/bridge/catalog.json) · [Setup guide](BRIDGE_SETUP.md)

**Status:** Website files are installed. No game data has been published yet. The site URL only works after GitHub Pages is enabled under Settings → Pages → main → /docs.

## What happens next
1. Enable GitHub Pages for `main` / `docs`.
2. Run the preconfigured TGC Live Bridge v3.1 EXE on the PC that holds bot exports.
3. Review a public-safe export folder and the exact preview filenames.
4. Enter a fine-grained GitHub Contents token locally in the EXE and start the mirror.

Your raw Discord archive, private channels and bot code should **not** be uploaded here. A random repository name is not access control; public repositories and Git history are publicly accessible. The synchronized snapshot is limited and may lag behind bot activity.
