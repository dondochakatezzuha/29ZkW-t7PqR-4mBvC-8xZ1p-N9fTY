This public site was installed for the TGC Discord archive. It currently only contains whatever the owner's local TGC Bridge has **explicitly approved and published**. The local bot and its full archive remain on the owner's PC.

## Getting the bot and website together

The owner's **TGC All-in-One v4 package** contains `TGC_Start_Everything_v4.exe` and `TGC_Live_Bridge_v4.exe`. When opened on the Windows PC with `D:\TGC`, the one-click launcher opens the existing bot startup script and the Bridge's local dashboard together. The Bridge then reads bot outputs. To publish a public-safe snapshot, enter a fine-grained token limited to this repo, check the exact filenames and contents, then click Start GitHub mirror. Checking the optional **Remember securely** box stores the token encrypted using Windows DPAPI and resumes previously approved syncing on future starts.

**GitHub Pages source:** branch `main`, folder `/docs` (already configured). The generated snapshot replaces the website inside `docs/` when it syncs. The repo URL stays stable.

**Important:** This is a public, incomplete mirror, not the whole private archive. A random repo name doesn't protect data. The current bridge has size/file limits and filters private/admin paths, but users still need to review text manually. Never publish bot tokens, personal data, or unapproved Discord messages.

**For future chats:** read [CHATGPT_READ_THIS.md](CHATGPT_READ_THIS.md), open the *current* catalog, and follow sources. Do not assume missing records are absent from the complete archive.
