# TGC Knowledge Library

This public repository hosts a **partial, opt-in mirror** generated by TGC Live Bridge v3. The local Discord bot writes to the owner's PC; the bridge reads the selected files and can update `docs/index.html` and `docs/bridge/*` every ~15 minutes while it stays open.

## Turn on GitHub Pages

1. In repository **Settings → Pages**, choose **Deploy from a branch**.
2. Pick branch `main` and folder `/docs`, then save.
3. The published URL should become: https://dondochakatezzuha.github.io/29ZkW-t7PqR-4mBvC-8xZ1p-N9fTY/

## Connect the local bridge

- In TGC Live Bridge v3 set repository to `dondochakatezzuha/29ZkW-t7PqR-4mBvC-8xZ1p-N9fTY`.
- Select a **reviewed, public-safe exports folder**. Don't select the entire bot directory or private Discord channels.
- Create a fine-grained personal access token scoped only to this repository with **Contents: Read/write** and enter it **locally into the EXE**, never into a chat.
- Click **Check what would publish**, review the entire filename list and representative file contents, then **Start GitHub mirror**.
- The bridge may publish up to 160 preferred text files / 7 MiB per snapshot and skips oversized sources. This is **not a backup of all TGC data**.

- The `file_url` values in the manifest are relative to the `docs/bridge/` folder, and each file is original source text, not automatically verified lore.

**Security:** This is a public repository. Its random name is not a security boundary. Search engines, link recipients, GitHub APIs, and repository history can expose content even if the site includes `noindex`.
